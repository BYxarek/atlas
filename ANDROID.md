# ATLAS для Android · v0.2.0

Нативная сборка Godot с библиотеками armeabi-v7a, arm64-v8a, x86 и x86_64. Интерфейс и карта отрисовываются движком, WebView не используется. Минимальная версия — Android 7.0 (API 24), требуется OpenGL ES 3.0. Текущий шаблон Godot нацелен на Android 16 (API 36).

## Установка

Скопируйте `build/Atlas-Android.apk` на телефон, откройте APK и разрешите установку из выбранного источника, если Android запросит это. При обновлении устанавливайте новую APK поверх старой. Удаление приложения или очистка его данных удаляет локальные кампании, настройки и ключ сетевого профиля.

Это подписанная release-сборка для непосредственной установки. Публикация в Google Play и AAB в эту задачу не входят.

## Управление и функции

- Касание выбирает страну, перетаскивание перемещает карту, жест двумя пальцами меняет масштаб. Кнопки `+`, `−` и `⌂` доступны без жестов.
- На небольшом портретном экране карточки открываются поверх нижней части карты; в альбомном режиме — сбоку. Содержимое меню и карточек прокручивается. Кнопки рассчитаны на касание, учитываются безопасные области экрана.
- Нижняя панель открывает армию, страны, ядерный арсенал и события. Кнопка `☰` открывает меню и статистику.
- Системная кнопка «Назад» сначала закрывает клавиатуру, диалог или карточку, затем открывает/закрывает игровое меню.
- При уходе в фон одиночная кампания сохраняется и ставится на паузу. Поворот экрана не сбрасывает кампанию. В сетевой игре отправляется запрос общей паузы; при утрате связи сервер применяет свой таймаут отключения.

Перенесены одиночная кампания, автоматические и ручные сохранения, экономика, улучшения армии, разведка, предупреждения, атаки и оборона, ядерные удары, анимации и звуки. Доступны LAN, VPS и PHP-хостинг. Серверные протоколы совпадают с Windows, поэтому телефон и компьютер могут участвовать в одной комнате. Качество соединения и ограничения Wi-Fi-хостинга зависят от устройства и сети; наиболее простой интернет-вариант — VPS или HTTPS PHP-сервер.

Локальные данные хранятся в каталоге приложения Android и доступны через игровые меню; дополнительных разрешений на общие файлы не требуется. Кампании и язык не синхронизируются автоматически между устройствами. Сетевой профиль также локальный: без переноса его ключа другой компьютер/телефон считается новым игроком.

## Русский и английский

На Windows и Android язык выбирается в **Настройки → Язык / Language**. При первом запуске используется русский для русскоязычной системы, иначе английский. Выбор сохраняется между запусками, применяется к интерфейсу, странам, уведомлениям, разведке и журналу, включая сообщения от русскоязычного сервера. Сохранённые события имеют единый исходный текст и переводятся при отображении, поэтому смена языка не меняет сохранение или результаты боёв.

Настройки экрана Windows остаются в версии для ПК; на Android вместо них действует мобильная компоновка с автоматическим поворотом.

## Сборка из исходников на Windows

Нужны Godot 4.8-beta2, Python, Android SDK Platform-Tools/Build-Tools и JDK 17 или новее. Подойдёт JBR из Android Studio. Android CLI (`android info`) помогает определить SDK; поддерживаются переменные `ATLAS_ANDROID_SDK` и `ATLAS_JAVA_SDK` для явного выбора путей.

```powershell
python tools/build_android.py
```

Скрипт при необходимости скачивает официальный Android export template, экспортирует APK, подписывает её и проверяет подпись и наличие нативных библиотек. Для обычного APK используется готовый шаблон без Gradle/NDK-сборки исходников движка. Если SDK ещё не установлен, используйте Android Studio или `android sdk install` согласно документации Godot. Шаблон уже содержит версии min/target SDK; для их изменения понадобится Gradle export.

При первой сборке создаётся отдельный ключ подписи в `%USERPROFILE%/.atlas/signing/android-release.jks`, пароль и псевдоним находятся рядом в `android-release.json`. Они не входят в репозиторий, APK и серверные архивы. **Сохраните резервную копию обоих файлов**: без прежнего ключа нельзя выпустить обновление, устанавливаемое поверх этой версии. Не публикуйте файлы подписи вместе с открытым исходным кодом. Владелец форка может использовать свой ключ и отдельный package ID.

Полная сборка Windows, серверных комплектов и Android:

```powershell
powershell -ExecutionPolicy Bypass -File tools/build.ps1
```

## Проверки

`tests/test_mobile.gd` проверяет мобильные компоновки, касания, pinch-to-zoom, фон/паузу, сохранение языка и переводы старых событий. Обычный запуск на ПК создаёт скриншоты портретного и альбомного интерфейса в `build`. `python tools/check_translations.py` проверяет покрытие строк.

У сетевых тестов есть `--mobile-ui --english`: они проверяют компактный английский интерфейс с настоящими VPS/HTTP-клиентами. APK проверяется `apksigner` и анализатором Android CLI. Запуск на физическом Android-устройстве в текущей среде не проверен: подключённых устройств нет, а установленный эмулятор требует отсутствующий гипервизор. Проверки компоновки выполнялись в нативном Godot на ПК с мобильными размерами окна; они не заменяют проверку клавиатуры, системных жестов, GPU и жизненного цикла на настоящем телефоне.

Официальные материалы: [экспорт Godot для Android](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_android.html), [локализация Godot](https://docs.godotengine.org/en/stable/tutorials/i18n/internationalizing_games.html).
