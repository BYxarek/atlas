# ATLAS на обычном PHP-хостинге

Этот вариант работает с доступом только к папке домена, HTTPS, настройкам PHP и cron. Docker, SSH, Node.js, Godot на сервере, база данных и постоянно работающий процесс не требуются. PHP сам рассчитывает экономику, армии, разведку, ботов и бои; клиент отправляет только команды.

## Установка через файловый менеджер или FTP

1. Создайте в домене отдельную папку, например `atlas`, и распакуйте в неё содержимое `Atlas-PHP-Hosting.zip`. Не смешивайте файлы с действующим сайтом.
2. В панели хостинга включите **PHP 8.1 или новее**. Нужны стандартные JSON, Hash, PCRE, `random_bytes` и файловые операции `flock`, `rename`; внешние расширения и запуск процессов через PHP не используются.
3. Включите действующий SSL-сертификат для домена. Адрес будет выглядеть как `https://example.com/atlas`. Windows-клиент не отключает проверку сертификата.
4. Скопируйте `config.example.php` в `config.php`. Проверьте, что PHP может создавать и изменять папку `_data`. Обычно её автоматически создаёт сам скрипт. Не назначайте права 777; используйте владельца PHP-процесса и права, рекомендованные вашим хостингом.
5. Откройте адрес папки в браузере: появится страница ATLAS. Затем в игре **Сетевая игра → PHP-хостинг · HTTPS**, введите адрес папки и нажмите **Подключиться к серверу**.

Можно вводить адрес папки либо полный адрес `https://example.com/atlas/api.php`. Адреса с query-параметрами, редиректами, пробелами и нестандартными символами пути не поддерживаются. Для разработки разрешён `http://127.0.0.1:порт` или `http://localhost:порт`; внешние серверы требуют HTTPS. Если хостинг включает страницу проверки браузера/CAPTCHA, исключите эту папку из такой проверки: нативный клиент ожидает JSON.

## Cron

В панели хостинга создайте задачу **раз в минуту**. В качестве команды укажите путь к PHP нужной версии и абсолютный путь к `cron.php`, например:

```cron
* * * * * /usr/bin/php /home/USER/www/example.com/atlas/cron.php
```

Реальные пути смотрите в панели хостинга: `/usr/bin/php` может относиться к другой версии. Настройка cron не требует SSH, если панель позволяет добавлять задания. В консоли успешный запуск выводит `{"ok":true,"rooms":…}`.

Если панель поддерживает только обращение к URL, задайте в `config.php` свой случайный `cron_key` длиной не менее 32 символов. HTTP-вызов `cron.php` по умолчанию закрыт. Передавайте ключ заголовком `Authorization: Bearer КЛЮЧ`, если планировщик поддерживает заголовки. Как запасной вариант можно использовать `https://example.com/atlas/cron.php?key=КЛЮЧ`; такой URL может попасть в журналы, поэтому не публикуйте его и не используйте в ключе пароль от аккаунта хостинга.

Скрипт cron быстро завершается, не остаётся работать в фоне и не запускает другие процессы. Игровое время продвигается также при обычных запросах игроков, поэтому минутный cron не означает минутную задержку ходов.

## Комнаты и возвращение

После подключения игрок видит список комнат и может создать свою. В комнате до 239 игроков и ботов. Администратор выбирает запуск после готовности всех, добавляет ботов, удаляет участников. Каждый выбирает свою страну и цвет. Старт одинаковый: 35 пехоты, 8 авиации, 4 корабля и 180 монет. В PvP можно потерять последнюю страну.

Финансы, результаты боя и разведданные рассчитывает PHP. Точные чужие войска не передаются до личной разведки. Повтор отправленного запроса после сетевой ошибки не повторяет покупку или списание денег.

Выход в лобби останавливает комнату. При потере связи сервер ждёт подтверждения присутствия игрока, по умолчанию до **20 секунд**, затем ставит комнату на паузу. Cron и запросы продвигают время только до истечения этого срока: длительное отсутствие не даёт часы дохода. Если администратор выходит, права получает другой подключённый человек. Все оставшиеся места должны подключиться и подтвердить готовность либо администратор удаляет отсутствующих участников.

После перезапуска PHP или хостинга данные остаются на диске. Подключитесь к прежнему адресу и выберите **Вернуться**. При аварийном закрытии клиента иногда нужно подождать до 20 секунд перед новым подключением того же профиля. Сохраняйте `%APPDATA%/AtlasWorldGame/network_identity.cfg` и прежний адрес сервера: из них получается ключ своего места. Основной локальный секрет серверу не отправляется. Перенос того же файла на другой компьютер при закрытой игре переносит профиль.

Список комнат публичный для пользователей этого сервера, код комнаты не является паролем. Сохранения этого PHP-варианта отдельные; автоматического импорта файлов VPS/LAN нет.

## Настройки и нагрузка

По умолчанию `max_rooms=4`, `poll_ms=1000`, `lease_seconds=20`. Предел комнат включает сохранённые и пустующие партии. Можно выбрать `max_rooms` от 1 до 16, интервал опроса от 750 до 5000 мс, ожидание связи от 10 до 120 секунд. При большем интервале опроса увеличиваются задержка отображения команд и плавность обновлений может снижаться; выставляйте ожидание связи значительно больше интервала опроса.

Для небольшого тарифа начните с 1–2 комнат. Один подключённый клиент делает примерно один запрос в секунду плюс запросы действий. Проверьте лимит PHP-запросов и CPU у своего провайдера. Это вариант для небольшой компании: для большого числа одновременных игроков используйте VPS. Нагрузочные пределы тарифов хостеров не измерены.

## Данные и резервные копии

Все данные находятся в `data_dir`: по умолчанию `_data/state.php`, предыдущая версия `_data/backup.php`, отдельный файл блокировки `_data/lock.php`. Запросы и cron используют общую файловую блокировку; запись сначала идёт во временный файл, затем заменяет основной. Ошибка записи возвращается клиенту, исходная версия не удаляется.

По возможности укажите в `config.php` абсолютный `data_dir` **вне папки сайта**, если хостинг разрешает PHP обращаться туда. Если доступна только папка домена, файлы данных имеют PHP-защиту и возвращают 404 при прямом HTTP-запросе. Убедитесь, что PHP действительно выполняется сервером, а не отдаётся как текст. Приложенный `.htaccess` дополнительно ограничивает листинг и доступ к служебным PHP-файлам на Apache; для работы через nginx приложение не полагается только на `.htaccess`.

Для резервного копирования на время отключите доступ к API и cron в панели, скачайте `state.php` и `backup.php`, затем включите доступ обратно. Не редактируйте JSON внутри файлов вручную и не удаляйте защитную первую строку. Для восстановления при остановленных запросах замените `state.php` своей копией либо файлом `backup.php`, сохраняя имя `state.php`. Файл блокировки оставьте на месте. Повреждённый файл не заменяется пустой базой: сервер возвращает ошибку, пока владелец не восстановит копию.

## Обновление и диагностика

Перед обновлением сделайте копию данных. Заменяйте только файлы программы, сохраняя **config.php и весь data_dir**. Используйте клиент из этого же релиза с поддержкой PHP-протокола 2. Текущий VPS-протокол не меняется.

Если вместо JSON приходит HTML, проверьте адрес, ошибки PHP, редиректы, CAPTCHA и ограничения ModSecurity. При ошибке хранилища проверьте права записи, свободное место и PHP error log. Никогда не включайте вывод ошибок с путями и содержимым данных в публичный ответ API. Если `.htaccess` вызывает 500 на вашем тарифе, согласуйте его директивы с хостером: PHP-защита файлов данных остаётся обязательной.

Основа: [flock](https://www.php.net/manual/en/function.flock.php), [hash_hmac](https://www.php.net/manual/en/function.hash-hmac.php), [HTTP-клиент Godot](https://docs.godotengine.org/en/stable/classes/class_httprequest.html).

## Diagnostics and consistent backups

Set `metrics=true` in your private config to log numeric request/storage timings to the PHP error log. Metrics contain no identities or request bodies. Optional CLI: `php storage.php backup DATA_DIRECTORY SNAPSHOT_FILE` and `php storage.php restore DATA_DIRECTORY SNAPSHOT_FILE`. Store snapshots outside the public web root; use the existing stopped-API FTP procedure when CLI is unavailable. Restore preserves `before-restore.php`. See `docs/TECHNICAL_IMPROVEMENTS.ru.md` in the source repository for the coordinated client/server update and rollback procedure.


Network mods / Сетевые моды: [единый формат .atlasmod для LAN, VPS и PHP](../docs/MODS.ru.md). Папка: `network_mods/` рядом с `api.php`; обновляйте клиент и сервер вместе (PHP protocol 5).
