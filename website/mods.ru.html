ATLAS / MODDING / 2026-11-05

Документация модов

От установки первого пакета до своего баланса и сетевой комнаты. Формат, все параметры, примеры и восстановление — в одном руководстве.

Документация для ATLAS 0.3.0 из ветки main. Версия игры, API модов и сетевой протокол имеют отдельные номера.

.atlasmodAPI 1 / 2Game 0.3.0LAN/VPS 11PHP 5

Что можно изменить

Один файл .atlasmod объединяет манифест и PCK. Для LAN, VPS и PHP используется один и тот же сетевой пакет, без пересборки под транспорт. Одиночная игра подключает PCK до загрузки сцены и статических данных. Сеть применяет проверенные changes и content API 2, а также прежний network_balance API 1; вложенный нативный код в сети не выполняется.

ОбластьОдиночная играLAN / VPS / PHP
Баланс, армия, экономика, ценыPCK / JSONAPI 2 changes / API 1 network_balance
Сроки операций, потери, вероятности, параметры ИИPCK / JSONAPI 2 changes / API 1 network_balance
Геометрия карты, число стран, нейтральные гарнизоныAPI 2 contentAPI 2 content
Звук, перевод, внешний видPCK / API 2 contentAPI 2 content
Новые механики и произвольный GDScriptЗамена игровых скриптовНе поддерживается

Внутренние функции игры не являются стабильным API плагинов. Нет встроенных Lua, JavaScript, хуков, Steam Workshop или автоматической конвертации скриптов в PHP.

Установка и управление

  1. Скачайте .atlasmod у доверенного автора. Распаковывать контейнер не нужно.
  2. Главное меню → Моды → Установить мод…. Выберите файл. Установка копирует его содержимое, но не включает мод.
  3. Нажмите Включить, подтвердите доверие автору, поставьте зависимости выше кнопками Выше / Ниже.
  4. Полностью перезапустите игру. Статус «Активен в этой сессии» показывает реально загруженный набор, а не только выбранный на следующий запуск.

Одиночный PCK может выполнять код и обращаться к файлам с правами игры. SHA-256 фиксирует одобренное содержимое, но не подтверждает безопасность автора. После изменения пакета выключите и включите его заново. Переустановка не перезаписывает существующий мод: для обновления выключите зависимые моды, затем сам мод, перезапустите игру, замените папку и включите заново. Для удаления выключите мод, перезапустите и удалите его папку. Сохранения перед этим скопируйте отдельно.

Вход в комнату и сетевой профиль

  1. Хозяин или сервер объявляет точный порядок, ID, версии, размеры и SHA-256 пакетов.
  2. Если ваш профиль отличается, появляется экран Нужны моды комнаты. До согласования набора вы не получаете место в лобби.
  3. Выберите Установить все нужные моды или отмените вход. Имеющиеся точные копии используются повторно; недостающее скачивается с этого же хозяина/сервера.
  4. Проверяются блоки, итоговый размер, SHA-256 контейнера, контрольная сумма PCK, манифест и общие правила. Повреждённый файл не активируется.
  5. Нажмите Перезапустить и подключиться. На ПК повторяется подключение и вход в комнату. На Android и во встроенном редакторе закройте и снова откройте игру: профиль и цель подключения сохранены.

Комната без модов предложит отключить текущий сетевой набор. Скачанные пакеты остаются в network_mods/cache/; набор хозяина лежит в корне network_mods/. Чужие кэшированные версии не включаются автоматически при создании своей комнаты. Кнопка Запустить с сетевыми модами формирует новый профиль из корневых файлов; Вернуться к одиночным модам возвращает одиночный набор после перезапуска.

Первый мод за несколько шагов

Скачайте SDK с тремя полными примерами и распакуйте в отдельную папку. Он содержит сборщик, минимальный проект Godot, исходный баланс и примеры; установки Python или npm не требуется. Нужен Godot 4.8-beta2 standard, без .NET. Запускайте команду из корня распакованного SDK, заменив путь к Godot своим.

& "C:\Tools\Godot_v4.8-beta2_win64_console.exe" --headless --path . --script tools/build_mod.gd -- examples/starter-economy dist/starter-economy.atlasmod

Пример выдаёт 1000 монет новой фракции. Один выходной файл установите через обычную или сетевую кнопку менеджера. В новой кампании/комнате проверьте 1000 монет. Старая кампания не получает стартовые ресурсы заново. Имя выходного файла должно оканчиваться на .atlasmod; существующий файл не перезаписывается.

my-mod/
  mod.json
  files/
    assets/
      balance.json

files/ становится корнем res:// PCK. Если единственный файл — files/assets/balance.json, сборщик автоматически добавляет полный network_balance. Поэтому один результат работает в одиночном и всех сетевых режимах.

В исходном манифесте нет путей для скачивания, установки или выполнения. Сетевой сервер передаёт собственный каталог и раздаёт только объявленные хеши. Не используйте ID вида ../mod, пробелы или кириллицу в ID; отображаемое имя может быть русским.

Диапазоны — границы валидатора, а не рекомендация по хорошему балансу. Огромные армии, нулевые цены или чрезмерные интервалы могут ухудшить игру и упереться в отдельные ограничения сохранений. Неподдерживаемые величины не превращаются автоматически в новые механики.

Формулы и единицы измерения

power = Σ(units[i] × unit_weight[i] × (1 + (level[i] - 1) × technology_bonus))
effective = power × (naval_multiplier if overseas else 1)
research_price = technology_cost × current_technology_level
business_upgrade_price = business_cost × current_business_level
attacker_loss_fraction = clamp(defense / max(effective, 1) × attack_loss, attack_loss_min, attack_loss_max)

При штатной армии [35, 8, 4] и технологиях [1, 1, 1] сила равна 75; в морской атаке с множителем 0.85 — 63.75. Для уровня технологии 2 при бонусе 0.25 соответствующая ветвь получает множитель 1.25. Улучшение предприятия уровня 3 при business_cost=25 стоит 75 монет и увеличивает доход с 3 до 4 монет в игровую секунду.

Равная эффективная сила достаточна для победы атакующего. Число потерянных единиц округляется вверх и ограничивается наличной армией. В бою учитываются армии и технологии на момент прибытия. Секунды относятся к симуляции; одиночная пауза останавливает её, личное меню в сети — нет.

Зависимости, порядок и конфликты

{
  "requires": ["base-rules"],
  "conflicts": ["alternative-rules"]
}

Одиночный менеджер не включает зависимости автоматически: сначала установите и включите base-rules, затем зависимый мод. Включение или перестановка, нарушающая порядок, отклоняется. В сетевом предложении уже должен присутствовать полный корректный набор; игрок скачивает весь нужный профиль.

Поздний пакет заменяет весь сетевой баланс. Если A меняет start_coins, а B — naval_cost, то B со штатным start_coins вернёт стартовые монеты к штатным. requires лишь проверяет наличие/порядок, а не объединяет параметры. Для совместного результата B должен содержать также изменения A. Укажите конфликты, если такое сочетание не задумано.

На хозяине/сервере файлы читаются по именам: 01-base.atlasmod, 02-addon.atlasmod. В кэше клиента имена основаны на SHA-256, а порядок берётся из серверного профиля. Одинаковый ID нельзя включить дважды. Название версии не заменяет побайтовую проверку файла.

Эти замены предназначены для одиночных PCK. Карта сейчас содержит 244 записи; COUNTRY_COUNT, массивы армий, ссылки соседства, геометрия, сохранения и интерфейс должны согласовываться. Изменение числа стран требует правок связанных скриптов, а не только JSON. Для переименования сохраняйте ID; для границ учитывайте обратные ссылки neighbors. Микрогосударства зависят от enclave_hosts и обработки раскрытия.

Минимальный визуальный пример: скопируйте актуальный src/world_map.gd в files/src/world_map.gd и измените UNKNOWN на Color("586c83"). Это замена всего скрипта; проверьте выбор стран, масштаб и сенсорное управление. Сетевой режим этот код игнорирует.

Для новой механики копируйте актуальный полный скрипт и сохраняйте существующие сигналы/контракты. Проверяйте все вызовы, загрузку и сохранение. Стабильных хуков on_attack/on_tick здесь нет, поэтому добавление таких имён само по себе ничего не подключает. Не заменяйте bootstrap, mods.gd и конфигурацию проекта без изменения самой игры.

Примеры одиночных изменений

Работайте с полными файлами актуального исходного проекта. Ниже показаны изменяемые фрагменты, а не самостоятельные файлы. Минимальный SDK содержит баланс и сборщик; игровые скрипты, карту и звуки берите из соответствующей сборки игры.

Переименовать страну

В полной копии world.json найдите запись по id и измените name/english. Сохраните остальные поля. id — индекс страны, continent — строка региона, center — пара [долгота, широта], rings — массив контуров из таких пар, neighbors — ID соседей, sovereign — ID суверена, enclave_hosts — окружающие страны для скрытого микрогосударства, dependencies — связанные зависимые территории. Поля связей должны ссылаться на существующие ID. Переименование не требует изменения геометрии.

{"id": 0, "name": "Новые Фиджи", "english": "New Fiji"}

Изменить нейтральную армию

В полной копии military.json поменяйте только armies[нужный_id], например armies[0] на [50, 5, 2]. Сохраните длину массива, порядок ID, balance_version и остальные поля. Для проверки начните новую кампанию и разведайте эту страну: существующее сохранение хранит собственные армии. start_units в balance.json задаёт другую сущность — армию новой фракции игрока/бота.

Изменить тему

Скопируйте src/main.gd в files/src/main.gd и замените константу INK, например на строку ниже. Это цвет обычного текста; также проверьте MINT, MUTED и фоновые цвета в build_theme/style. Обеспечьте читаемость, фокус клавиатуры и размер текста на телефоне.

const INK = Color("fff2d9")

Изменить английскую подпись

В полном assets/i18n/en.json можно заменить значение ключа «Настройки» на Preferences. Русский интерфейс использует исходные русские строки, поэтому изменение английского каталога не переименует русскую кнопку.

{"Настройки": "Preferences"}

Изменить фиксированную механику

Сила ядерного удара не является полем network_balance. Для одиночной модификации нужна полная копия src/game.gd: в обработке прибытия операции nuke замените коэффициент 0.5 на 0.4. Это оставит 40% войск с округлением вниз. Обновите также сообщение о результате (60% потерь), перевод и связанные проверки. Сохраните отмену удара по уже своей стране и возврат заряда. Такое изменение не становится сетевым: для общего нового правила нужно расширение схемы и обеих реализаций симуляции.

countries[target].units[i] = floori(countries[target].units[i] * 0.4)

Графика, звук и переводы

Простой сборщик принимает только json, gd, tscn, tres, gdshader, txt, csv. PNG, SVG, OGG и другие импортируемые ресурсы сначала импортируйте в Godot 4.8-beta2 с путями игры. Экспортируйте выбранные изменённые ресурсы и их зависимости через Export PCK/ZIP → PCK, назовите результат content.pck и положите рядом с mod.json. Затем запустите тот же сборщик: при наличии content.pck он оборачивает готовый пакет и не читает files/.

Для своего звука победы замените res://assets/audio/victory.ogg. События click, select, open, cancel, confirm, error, save, coins, upgrade, unlock, warning, all_clear, invasion, report, rocket_launch, rocket_loop, start, victory, defeat, campaign_win, campaign_lose, spy_send, spy_loop, naval_loop, army_loop, march, march_naval, battle, battle_naval, nuke, notification читаются по этим именам. Петли army_loop/naval_loop/spy_loop/rocket_loop зацикливаются скриптом. Само добавление music.ogg не создаёт музыкальный плеер.

Перевод заменяет полный assets/i18n/en.json. Сохраняйте ключи русских строк и форматные маркеры %s, %d, %.1f и %% с нужным порядком/количеством. Имена стран берутся из полей name/english атласа. Третий язык требует правки i18n.gd и выбора языка в интерфейсе.

В экспорт включайте импортированные зависимости, но не project.godot/project.binary, загрузчик, глобальные UID/class-кэши. Проверьте Windows и Android отдельно: импорт текстур и нативные расширения могут зависеть от платформы. В сети медиа и локализация из PCK не применяются.

prepared-mod/
  mod.json
  content.pck

godot --headless --path . --script tools/build_mod.gd -- prepared-mod dist/prepared-mod.atlasmod

Хозяин LAN, VPS и PHP-хостинг

LAN

Установите сетевые .atlasmod в корень network_mods через менеджер. Нажмите «Запустить с сетевыми модами», перезапустите и создайте лобби. Другие игроки подключаются обычным способом по LAN/адресу; предложение модов приходит от хозяина. По умолчанию игровой UDP-порт — 24760, обнаружение LAN использует 24761.

VPS

Положите те же файлы в ATLAS_MODS_DIR. По умолчанию — user://network_mods; Docker задаёт /data/network_mods. Запускайте сервер с переменными ниже. Для Docker папка должна находиться в смонтированном томе /data; для загрузки с хоста можно добавить bind mount каталога network_mods в /data/network_mods:ro. Не помещайте туда клиентский cache.

export ATLAS_MODS_DIR=/srv/atlas/network_mods
export ATLAS_DATA_DIR=/srv/atlas/data
export ATLAS_PORT=24760
export ATLAS_MAX_ROOMS=8
godot --headless --main-pack AtlasServer.pck -- --server

Это перечень переменных окружения: в Linux задайте их через export или менеджер сервиса перед командой; в PowerShell используйте $env:NAME="value". Клиенты подключаются по wss:// с действительным сертификатом; незашифрованный ws:// разрешён только для localhost/127.0.0.1.

PHP

Рядом с api.php создайте network_mods/ и загрузите те же .atlasmod. Нужны обновлённые mod_catalog.php, mods.php, service.php и simulation.php из одной версии серверного пакета. PHP 8.1+ использует JSON/Hash/PCRE и файловую систему; ZIP и запуск Godot на хостинге не требуются. Каталог читается при запросе; mods.php раздаёт только объявленные пакеты блоками. Клиенты используют HTTPS; HTTP допустим только на localhost/127.0.0.1.

В config.php задаются data_dir, max_rooms (1–16), poll_ms (750–5000), lease_seconds (10–120), metrics и cron_key. Это настройки хостинга, а не поля мода. Не меняйте их через network_balance. Права записи требуются для data_dir; выставлять 777 не нужно. cron_key храните приватно; CLI cron ключа не требует.

Обновление

Один экземпляр сервера использует один фиксированный профиль для всех своих комнат. Для разных наборов запускайте отдельные экземпляры. Остановите сервер/закройте доступ к PHP-комнатам, сохраните резервную копию данных, замените пакеты и обновите сервер с клиентами вместе. LAN/VPS wire=11, PHP protocol=5. После изменения профиля прежние комнаты не мигрируют автоматически: верните прежний профиль для их продолжения.

В Windows user:// обычно находится в %APPDATA%/AtlasWorldGame; точный путь виден в менеджере. В Android это приватные данные приложения, доступ зависит от системы; очистка данных/удаление приложения удаляет кампании и сетевую идентичность.

Одиночный отпечаток включает упорядоченные ID, версии и SHA-256 PCK; сетевой — ID, версии и SHA-256 полных .atlasmod. Даже изменение описания сетевого контейнера меняет его хеш. Сохранения другого профиля отклоняются до изменения текущей кампании. Переименование имени .atlasmod само по себе не меняет содержимое, но на хозяине может изменить порядок. Удаление мода не является миграцией сохранений. Старые файлы сохраняются, однако для чтения нужно вернуть точный набор и порядок.

Контейнер и ограничения передачи

ЧастьРазмерОписание
Magic8 bytesATLASMOD ASCII
Manifest length4 bytesuint32 little-endian
Manifest2…4 194 304 bytesUTF-8 JSON + pck_sha256
Payloadremaining bytesGodot PCK, GDPC header

Весь файл — не более 64 MiB (67 108 864 байта). Сетевой профиль — до 32 пакетов и 128 MiB суммарно. Размер блока — 65 536 байт. Передача проверяет ожидаемый хеш, точное смещение и размер блока; после записи проверяется полный файл. Нативный сервер ограничивает раздачу 64 запросами блоков в секунду на клиента и сроком предложения 10 минут; клиент ждёт блок до 15 секунд. HTTP-загрузчик имеет таймаут 10 секунд и не следует перенаправлениям.

Контейнер не ZIP: переименование обычного ZIP или PCK в .atlasmod не создаёт мод. Сборщик создаёт заголовок, JSON и контрольную сумму. Нельзя «исправить» хеш скачанного файла вручную: сервер сравнивает точное содержимое. При изменении версии автору нужно собрать новый файл и обновить серверный набор.

Флаг пропускает и одиночные PCK, и сетевой профиль. Для постоянного сброса сети выберите возврат к одиночным модам или переименуйте network_boot.json. Не удаляйте network_identity.cfg: он связан с вашим местом в сетевых комнатах. После неудачного запуска одиночного PCK следующий старт пропускает его автоматически. Уже подключённые PCK не выгружаются на лету, поэтому после частичной ошибки нужен новый процесс игры.

Если в вашей сборке нет меню «Моды», это предыдущая сборка клиента, а не ошибка формата файла. Страница описывает разрабатываемый функционал; сверяйте клиент, сервер и наличие сборщика.

Проверка и выпуск своего мода

  1. Соберите пакет в новый файл. Проверьте ID, версию и описание.
  2. Одиночный мод проверьте в новой кампании, после сохранения/загрузки, на паузе и при завершении партии.
  3. Для сетевого мода подключите второй чистый клиент, откажитесь от установки, затем согласитесь. Проверьте скачивание, перезапуск, вход и одинаковые значения параметров.
  4. Проверьте профиль без модов, обновление пакета, зависимости, конфликт и возврат старого сохранения. Для медиа/интерфейса проверьте целевые платформы и маленький экран.
  5. Распространяйте один .atlasmod с указанием версии игры, ID зависимостей и изменений. Не включайте сохранения, сетевую идентичность, локальные конфиги или секреты сервера.
python tools/test_godot.py tests/test_mod_package.gd
python tools/test_godot.py tests/test_mods.gd
python tools/test_network_mods.py
./tools/build.ps1 -ChecksOnly

Эти проверки запускаются из полного исходного проекта, а не из минимального SDK. Сетевой тест передаёт один и тот же файл блоками через LAN, VPS и PHP, запускает клиент новым процессом и сверяет правила. Все примеры здесь собраны на основе текущего полного balance.json.

API 2: переносимый контент

Используйте API 2 для новых модов. Поля манифеста ID/версия/зависимости остаются прежними; pck_sha256 добавляется сборщиком. changes и content необязательны. ID содержат строчные латинские буквы, цифры, _ и -, до 64 символов. Цена и доход — целые; неизвестные поля контента отклоняются. Каталоги объединяются по порядку модов, повторяющиеся ID отклоняются. scenario, victory и map позднего мода заменяют объект целиком; theme/assets/переводы объединяются по ключам.

До 64 ресурсов, до 192 КиБ декодированных данных на ресурс. Суммарный манифест до 4 МиБ. Ресурсы передаются внутри одного .atlasmod; PNG/WAV декодируются клиентом, PHP их не исполняет.
content.panels[]До 16 панелей: id, title (до 160 символов), text (до 1024), action="". Отображаются в карточке армии. action открывает army, economy, countries или notifications. Это текст и стандартные кнопки без HTML/JavaScript.

Сборка и инструменты

godot --headless --path . --script tools/build_mod.gd -- examples/frontier dist/frontier.atlasmod
godot --headless --path . --script tools/mod_tool.gd -- validate dist/frontier.atlasmod
godot --headless --path . --script tools/mod_tool.gd -- inspect dist/frontier.atlasmod
godot --headless --path . --script tools/mod_tool.gd -- save-check dist/frontier.atlasmod campaign.json

В игре: Моды → Инструменты модов. Видны итоговые значения, источник каждого изменения и перекрытия. Проверка пакета проверяет добавление к текущему набору; проверка сохранения ничего не записывает. Тестовая кампания сохраняет текущую и создаёт отдельную новую; в сетевой комнате сначала выйдите из неё. Сохранения разделяются по точному отпечатку пакетов. Автоматическая миграция при изменении модов не выполняется: возвращайте исходный набор. Для зависимостей валидируйте весь упорядоченный профиль; отдельный пакет с внешними ссылками не является самостоятельным сценарием.

SDK включает исходник Frontier. Старые три примера API 1 сохранены для совместимости. Мод API 2 без files/ автоматически получает пустой PCK. Редактор сайта создаёт такой пакет для нового проекта и сохраняет исходный PCK при импорте API 2. Экспорт браузера не заменяет полную проверку компилятора SDK.

Расширенный конструктор

Формы объектов

Выберите тип объекта, заполните форму и нажмите «Сохранить объект». Для изменения существующего нажмите его ID. Требования выбираются из списка технологий. ID определяет заменяемый объект; изменение ID создаёт новый. Исходный JSON доступен рядом. Формы сценария отдельно задают стартовые армии, уровни, гарнизоны, исследования, союзы и цели победы.

Карта

Выберите страну на карте или в списке. Меняйте название, столицу, суверенитет и зависимости. Сохранение соседей исправляет обратные ссылки. Для точной работы приблизьте выбранный остров кнопкой масштаба. Вершины двигаются мышью или точными координатами; можно вставлять и удалять вершины, добавлять острова и создавать страны прямоугольником. Новая карта начинается с трёх стран. Удаление страны разрешено после удаления ссылок из сценария/событий/медиа и перенумеровывает последующие ID. Проверяются самопересечения, нулевая площадь, координаты, взаимность границ и геометрические разрывы заявленных соседей. Для сложных границ проверка имеет ограничение работы и выдаёт предупреждение.

Блоки событий

Выберите events. Блок «Когда» задаёт триггер; «Если» соединяет условия И; действия исполняются по порядку. Есть одноразовость, задержка повторения, флаги и перестановка действий. Сначала сохраните событие. В разделе теста задайте монеты, время, начальное значение генератора и дополнительное состояние. Отчёт показывает сработавшие события и причины пропуска: условия, шанс, одноразовость/задержка, бюджет. Это проверка событий, а не полная симуляция игры.

Предпросмотр и диагностика

Карточки показывают контент, требования и тему; дерево исследований — связи; PNG можно просмотреть, WAV прослушать. Кнопка проверки показывает ошибки и предупреждения отдельно. Ошибка содержит путь, например content.events[0].actions[1].unit. Нажатие открывает соответствующий объект. Ошибки блокируют экспорт; предупреждения требуют оценки автора. SDK остаётся окончательной проверкой полного набора.

Проекты и история

Черновик автоматически сохраняется в localStorage этого браузера и восстанавливается отдельной кнопкой. Отмена/повтор сохраняют до 20 состояний в пределах 8 МиБ истории. Если места браузера недостаточно, редактор сообщает об этом: скачайте .atlasproject. Этот файл содержит манифест, исходный текст, ресурсы/PCK, пакеты сборки, предыдущую версию и отчёт. При импорте API 2 .atlasmod произвольный PCK сохраняется как непрозрачные данные; редактор его не выполняет и не заменяет пустым. API 1 редактируется исходными инструментами. Черновики не синхронизируются между устройствами.

Совместимость

Загрузите предыдущий JSON или .atlasmod для сравнения полей. Отдельно отмечаются удалённые ID, изменение порядка войск, карты, ID мода и версии игры. Даже изменение описания меняет точный сетевой пакет: структурное сравнение не означает совместимость сохранения. Проверка сетевого сохранения сравнивает его mods с отпечатком выбранной сборки. Одиночные отпечатки проверяются игровым инструментом. Автоматическая миграция не выполняется; исходные файлы сохраняются.

Проверка баланса

В конструкторе выберите sessions (1..100), seconds (1..86400), bots (2..16) и seed (1..2147483646), скачайте план и экспортируйте пакет. Запустите команду ниже из SDK или исходного проекта игры, где доступен Godot; путь к программе можно передать как --godot PATH. Используется настоящая сетевая симуляция с теми же правилами и ИИ. Стартовые страны чередуются между сериями; пересекающиеся старты пропускаются, нехватка стран останавливает тест. Отчёт содержит результаты партий, победы по стартовым странам, доход, время первого расширения, динамику развития, найм войск, финальные армии, исследования и предупреждения о малой выборке/неиспользуемых войсках. Можно сравнить с предыдущим отчётом; одинаковый план и seed дают повторяемый результат. Существующий отчёт не перезаписывается. Импортируйте результат обратно в конструктор. Полная игра и пакетные бои не запускаются в браузере.

Сборки модов

Добавьте .atlasmod в разделе сборки, упорядочьте вручную или по зависимостям. Проверяются ID, версии игры, requires/conflicts, контрольные суммы и объединённый контент. Экспорт .atlaspack содержит точные исходные пакеты, порядок, версии, размеры и SHA-256. Lock-файл содержит только описание набора. В игре «Моды → Установить сборку модов…» проверяет файлы, сохраняет выбранный сетевой профиль и требует перезапуска. Для VPS/PHP распакуйте сборку SDK-командой в НОВУЮ папку и используйте полученные нумерованные .atlasmod как корневой набор network_mods. При существующей папке распаковка отказывается от записи. Комнаты продолжают использовать общий профиль сервера и обычное предложение установить необходимые моды.

content.ai

Объект задаёт одинаковое поведение ботов в LAN/VPS/PHP. priorities — до 32 правил по порядку. Первое доступное действие срабатывает, иначе используется обычная логика игры. action: research, construct, recruit, upgrade, business. id — ID исследования/здания/войск; для business не нужен. reserve — сохраняемый запас монет (0..100 000 000), max_level — предел уровня/численности (по умолчанию 10). requires и стоимость проверяются как для игрока. attack_ratio (0..2, по умолчанию 1) умножает обычный порог допустимой силы цели. targets: weakest, income или nearest (сначала сухопутные цели). retreat_ratio (0..2, по умолчанию 0) отменяет текущий марш атаки, если эффективная сила меньше обороны × коэффициент; цена операции не возвращается. Правила ИИ применяются только к сетевым ботам, включая тесты баланса.

{"ai":{"priorities":[{"action":"research","id":"metallurgy","reserve":20},{"action":"construct","id":"forge","max_level":3},{"action":"recruit","id":"cannon","max_level":30}],"targets":"income","attack_ratio":1.1,"retreat_ratio":0.8}}
python tools/test_mod_balance.py --config balance-plan.json --output balance-report.json frontier.atlasmod
python tools/test_mod_balance.py --config balance-plan.json --output next-report.json --baseline balance-report.json frontier.atlasmod
godot --headless --path . --script tools/mod_set.gd -- unpack mod-set.atlaspack NEW_DIRECTORY

Формат .atlaspack: 8 ASCII-байт ATLASSET, uint32 LE длина индекса (до 64 КиБ), UTF-8 JSON {version:1,mods:[{id,version,size,sha256}]}, затем .atlasmod подряд в этом порядке. До 32 пакетов, 128 МиБ суммарных пакетов. Никаких путей и адресов загрузки в индексе нет. Ошибка проверки не меняет выбранный профиль; готовые файлы сначала проверяются во временной папке.
